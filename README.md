# ♟️ The Pawns Game

A fast-paced, pawn-based strategy game inspired by the simplicity of chess, but with its own gameplay and identity.

## 🎮 Features

* ♟️ Pawn-based strategic gameplay
* 🤖 AI opponent — Mikhail Tal-inspired opponent
* ⏱️ 1+2 game timer
* 🔊 Move and capture sounds
* 🎵 Sound ON/OFF toggle
* 🏃 Dinosaur runner animation
* 📜 Previous move history
* 🏳️ Resign button
* 🔄 New Game button
* ✨ Smooth pawn movement
* 📱 Mobile-friendly interface

## 🧠 Game Concept

The Pawns Game focuses on tactical pawn movement and decision-making on an 8×8 board. The goal is to create a simple-to-learn but challenging strategy game with a unique visual and audio experience.

## 🤖 AI Opponent

The game features a **Mikhail Tal-inspired AI opponent**, designed as a tribute to the legendary attacking chess player.

> The AI character is inspired by Mikhail Tal and is not intended to represent an official Mikhail Tal product or endorsement.

## 🔊 Audio

The game includes separate sounds for normal moves and captures. The original capture sound is preserved.

## 📱 Mobile Support

The interface is designed to work comfortably on mobile devices, with responsive board sizing, controls, timers, and game information.

New features, improvements, balancing, animations, and AI enhancements are still being worked on.
